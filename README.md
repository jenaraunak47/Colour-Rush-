# 🎨 Color Rush

A fun, fast-paced color recognition game built with HTML, CSS, and JavaScript. Test your reflexes and see how many points you can score in 30 seconds!

## 🎮 Live Demo

[Play Color Rush](https://jenaraunak47.github.io/Colour-Rush-/)

## 🕹️ How to Play

1. Click **Start Game**.
2. Look at the color of the displayed word.
3. Select the button matching the font color, not the word itself.
4. Score as many points as possible before the timer runs out!

## ✨ Features

- 30-second countdown
- Random color challenges
- Real-time score tracking
- High score saved in browser local storage
- Responsive interface

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
